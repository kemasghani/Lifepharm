# Exigo API — Company-specific lookup fields

Back to [index](README.md).

These properties take IDs whose valid values are configured per Exigo company (for example warehouses, ship methods, price types, currencies, countries, customer types/statuses, rank IDs, periods). The docs expose them through `doc/ListHelp.aspx`, which **requires an Exigo developer login** (API login name, password, company), so the values are not public. For LifePharm, read them from our Exigo instance with these credentials, or use the list operations in the API (for example `GetWarehouses`, `GetShipMethods`, `GetCountryRegions`, `GetRankQualifications`) where available.
